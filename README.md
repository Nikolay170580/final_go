# 🗓️ Планировщик задач на Go

Веб-сервер для управления задачами с поддержкой повторений, поиском и аутентификацией.

## ✨ Функционал

- ✅ Добавление, редактирование, удаление задач
- ✅ Повторение задач: ежедневно (`d N`), ежегодно (`y`), по дням недели (`w 1,3,5`), по дням месяца (`m 15,28`)
- ✅ Поиск задач по заголовку/комментарию или дате
- ✅ Грациозное завершение сервера
- ✅ Аутентификация через JWT (опционально)
- ✅ Переменные окружения для конфигурации

## 🚀 Локальный запуск

```bash
# 1. Клонировать репозиторий
git clone <your-repo>
cd final_go

# 2. Установить зависимости
go mod tidy

# 3. Запустить сервер (опционально с переменными)
set TODO_PORT=7540
set TODO_DBFILE=scheduler.db
set TODO_PASSWORD=  # оставить пустым для отключения аутентификации
go run main.go

# 4. Открыть в браузере
http://localhost:7540
